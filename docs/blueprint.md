# **App Name**: Tamil Research Validator

## Core Features:

- Firebase Authentication: Implement secure user authentication with Firebase, including single-sign-on (SSO) capabilities and local persistence for user convenience.
- Knowledge Hub: A repository of research papers and code books (e.g., IS 801) accessible via an integrated internet search tool, aiding users in finding relevant CFS resources. The tool will also use the internet search results to answer a user's prompt about a specific piece of information found within search results.
- Material Matrix: Manage specific design members and their material properties (e.g., thickness, yield strength, web height) for the Material Matrix.
- Validation Page: Enable side-by-side entry and comparison of practical laboratory results versus Abaqus CAE simulation results.
- Results Page: Automatically calculate the Error Percentage to compare the entered validation data, display a verification status, and generate Load-Displacement charts.
- Tamil Language Toggle: Add toggle to change app language.
- Firestore Integration: Database integration using Firestore

## Style Guidelines:

- Primary color: Turmeric Yellow (#FFC30B) to represent a traditional and inviting aesthetic.
- Background color: Light tan (#F2D7B5), creating a warm and neutral canvas. It’s derived from the Turmeric Yellow.
- Accent color: Temple Terracotta (#800000), providing a bold contrast that complements the primary color. It will highlight interactive elements.
- Body and headline font: 'Inter', sans-serif.
- Use icons inspired by Tamil Nadu culture and architecture.  Ensure icons are simple, clear, and consistent throughout the application.
- Implement a grid-based layout with sufficient white space to ensure a clean and organized interface. Use subtle Kolam patterns as background textures to enhance the Tamil Nadu cultural theme.
- Incorporate smooth transitions and subtle animations on user interactions to improve usability. Use loading animations inspired by traditional Indian art forms to match the overall cultural theme.
